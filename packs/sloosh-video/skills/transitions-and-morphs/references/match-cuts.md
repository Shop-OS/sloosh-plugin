# Match-cut catalogue

Use this catalogue to plan the change from one shot to the next. Each entry says when to use the cut, how to set up frame A (the last frame of the outgoing shot) and frame B (the first frame of the incoming shot), and whether a generated bridge clip helps.

A bridge is one start-frame and end-frame clip that moves from A to B. A hard cut needs no generation. When a generated bridge does not land exactly on B, a hard cut to B in the edit is the safe fallback.

## 1. Rules for every cut

- Put the cut on the frame where the new picture must first be seen. That is 0 to 2 frames before the spoken word that names it.
- Keep motion blur from crossing a cut. The first frame after a cut is sharp.
- A hero cut can take one accent: a 2-frame colour split or a sound effect whose peak lands on the cut frame. Do not stack more than one effect on a cut.
- An overlay that tracks the object (a box, a crosshair, a label) stays across the cut. Change only its text, such as "YOUR CAKE" to "ON THE MOON". That continuity sells the cut.
- Check the cut with a 50% blend of the frames on each side of it. The shared object must look like one object.
- For a bridge, frame A and frame B must have the same aspect ratio, the same subject position and scale, and the same camera height.

## 2. Object-locked photo cut

Use it when the same object moves to a different world, such as a source photo becoming a generated scene.

1. Measure the object box in both images. Use a stable part of the object, such as a cake body, a cup body or a chair seat, not a part that differs.
2. Scale and offset each image so the boxes match and both images still fill the frame.
3. Move one virtual camera across both images: the same slow push before and after the cut. Continuing the push across the cut makes it seamless.
4. If the object faces a different way in each image (a handle on the left versus the right), mirror the source only when no text or logo shows. Otherwise remake one frame. Tell the user.

Bridge: usually not needed. If the two worlds must blend, make a 3-second bridge with the object locked in place.

## 3. In-frame swap (print or card)

A photo print or a card stays still. Its content swaps from the source to the result, with the object at the same place inside the card. Match the object centre and width inside the card, as in entry 2. The card can then open into a grid or shrink into a layout.

Bridge: optional. A short bridge can dissolve the card content while the card stays locked.

## 4. Window expand

Show the source through a window cut into a paper sheet, placed where the result's object will sit. On the cut, the window grows to the full frame and the image swaps to the result. Keep any zoom on the window content going in the next shot.

Bridge: not needed. Make it as a hard cut or as an effect in the user's editor.

## 5. Tile expand

A contact-sheet tile grows to the full frame. Its crop moves from the tile crop to the next shot's opening view. Finish the growth 1 to 2 frames before the cut, so the last frame equals the next shot's first frame.

Bridge: not needed. Make it as a hard cut or as an effect in the user's editor.

## 6. Zoom-through

Push into a dark or solid shape until it fills the frame. Start the next shot on that colour. Ease in, and finish 1 to 2 frames before the cut so the last frame is solid.

Bridge: frame A is the wide shot. Frame B is the detail. Prompt: "The camera pushes into [the element in A] until it fills the frame, and the frame becomes B without a cut." Keep it to about 3 seconds.

## 7. Graphic match

End a beat on a graphic (a badge, an icon, a button) that is centred and large. Start the next shot extremely close on the same graphic, then pull back. Match the position and the size on screen.

Bridge: not needed. Make it as a hard cut or as an effect in the user's editor.

## 8. Colour or pixel-block wipe

A clicked accent element starts a stepped wipe of square blocks. The blocks sweep in one direction with a little noise. The wipe ends on a solid accent frame, which is the background of the next shot.

Bridge: not needed. Make it as a hard cut or as an effect in the user's editor.

## 9. Push-in hand-off between screen states

Push the camera into the element that was just clicked (a card thumbnail, an upload slot) until it fills the frame. Open the next shot on the same content at the same size, then pull back.

Bridge: not needed. Make it as a hard cut or as an effect in the user's editor.

## 10. Whip pan

The outgoing content speeds up sideways. The incoming content arrives in the same direction and slows down. Blur it along the motion so it reads as a smear, not as strobing copies.

Bridge: a 1 to 2 second bridge works when A and B share a direction. Prompt: "A fast whip pan to the right, the frame smears, and it settles exactly on frame B."

## 11. Flash or shutter

Use it for a photograph or camera beat. A white flash ramps to full on the last frame of the outgoing shot and fades over about 6 frames in the new one. The shutter sound peaks on the cut.

Bridge: not needed. Make it as a hard cut or as an effect in the user's editor.

## 12. Feature match between different photos or clips

Eye to eye, a painted horizon to a real horizon, a printed bottle to a photographed bottle, a round object to a round object. Measure the feature point and its size in both frames. For a clip, measure on the exact frame you cut on. Place and zoom each so the feature has the same screen position and size. Push in on the outgoing feature for a few frames and continue the push on the incoming one. For a video, start the incoming clip on a frame whose feature matches.

Bridge: this is where a generated bridge helps most. Frame A and frame B hold the feature at the same place. Prompt: "The [feature] stays fixed in the frame while everything around it changes from A to B."

## 13. Continuous camera

This is not a cut. A layout changes into the next one, such as a campaign board spreading into the floating cards of an end card. Move each element's box from the first layout to the second.

Bridge: a scene change with the camera locked. Describe what enters, what leaves and what stays.

## 14. Sketch-to-photo reveal

A hand-drawn idea is drawn stroke by stroke, placed so its key shape sits over the real object in a photo. The photo fades or wipes in under the strokes, then the strokes fade. It pays off an earlier idea beat. Fit the sketch's box to the object's box in the photo.

Bridge: frame A is the sketch over a plain background. Frame B is the photo with the object in the same place. Prompt: "The pencil lines fill with colour and texture and become the photo, with the object fixed in place."
