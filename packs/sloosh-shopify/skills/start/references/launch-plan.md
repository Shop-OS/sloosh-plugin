# Launch set plan

Planning costs nothing. Write the plan in the chat and get the user's approval before any quote.

## Image rounds

- Plan catalog images and ad images for the chosen products.
- Use the photo style, channels and aspect ratios from the brand kit.
- If a store audit ran, fill its first sprint gaps first.
- For each clip, plan one image in the clip's aspect ratio, unless a planned image already has that aspect ratio. It becomes the start frame.
- Keep the copy out of the images.
- For 9:16 placements, keep the product and any text out of the top 14%, the bottom 35% and 6% at each side of the frame.

## Ad copy

- Write the ad angles and the copy for each placement in the chat.
- Use the copy limits for each placement from the launch-ads skill.
- Use only claims the user gives or the store shows. Do not invent reviews, ratings, quotes or offers.
- Before you quote copy that uses a customer review, ask the user to confirm they may use it. If they decline, do not use it.

## Clip rounds

- Plan one clip per chosen product.
- Set each clip's motion preset, aspect ratio and length with the presets from the pdp-video skill.
- A clip cannot be quoted before its start frame exists.

## Round size

- Put at most 8 generations in a round.
- Run every image round before the first clip round.

## Update the brand kit

- Add imported product image ids to Hero products only for products already listed there.
- Add the best new images to Sloosh assets, with a one-line note each.
- In Claude Code or Cowork, edit sloosh-brand.md and add a line under Updated.
- In the Claude app, give the user the updated file. Tell them to replace the file in the Project's knowledge, or to save it to memory if memory is on.
- Do not say the kit is saved unless you saved it.
