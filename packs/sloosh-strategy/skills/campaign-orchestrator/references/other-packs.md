# Other Sloosh packs

The campaign-orchestrator skill uses these packs only when they are installed. If a pack is not installed, use the nearest core skill and tell the user what the pack would add.

- If the Sloosh ads pack is installed, use its hook grid skill for three hooks in three framings, its sale banner skill for an offer and its creator video ad skill when the user has a creator photo.
- If the Sloosh video pack is installed, use its cinematic product film skill for a multi-shot film and its captions skill for burned-in captions.
- If the Sloosh image pack is installed, use its upscale and finish skill for final files and its reframe skill for a new ratio.
- If the Sloosh ecommerce pack is installed, use its listing pack skill for a marketplace set and its multi-angle skill for more angles.
- If the Sloosh brand pack is installed, use its brand kit skill before round 1 and its logo animation skill for a logo sting.
- If the Sloosh social pack is installed, use its carousel skill for carousels and its Reels and Shorts clip skill for short vertical clips.
- If the Sloosh motion pack is installed and the host runs local commands, use its motion director skill for stylised motion pieces.
- If the Sloosh Shopify pack is installed, use its launch ads skill for a Shopify launch ad set with copy for each placement.

No core skill makes upscales or captions. Without the image or video pack, leave them out of the plan and tell the user.
