# Colour prompts

Each colourway prompt has three parts in this order: the recolour line, the keep-list and the guard line. Write one prompt per colour. Keep the keep-list and the guard line the same for every colour in a set. Change only the colour words.

## Skeleton

```
Recolour only the [upper / body / fabric] of the product in reference 1 to [sage green (#9CAF88)].
Keep identical: the shape, [the sole, the metal hardware, the logo, the stitching, the label], the material texture, the highlights, the shadows, the background and the framing.
Same photograph, only that colour changes. No text.
```

## Zones and keep-lists by product

| Product | Recolour zone | Usual keep-list |
|---|---|---|
| Bag or tote | the body panels and the straps | metal hardware, zips, the logo plate, edge paint, stitching, the lining |
| Sneaker or shoe | the upper | the sole, the laces, the logo, the heel tab, stitching, eyelets |
| Garment | the fabric | buttons, zips, the printed logo, labels, trims, the model's skin and hair |
| Furniture | the upholstery or the frame finish | the legs, the cushions' shape, seams, piping, the floor and the wall |
| Cosmetics pack | the bottle or the cap | the label text, the pump, the logo, the glass clarity |
| Small electronics | the shell | screens, buttons, ports, the logo, the lens |

## Finish words

| Finish | Words to add |
|---|---|
| Matte | flat matte finish with soft, wide highlights |
| Gloss | high-gloss finish with sharp, small highlights |
| Metallic | brushed metallic finish that keeps the source reflections |
| Suede or nubuck | soft suede nap with no shine |
| Patent | mirror-like patent finish with crisp reflections |
| Pattern or print | the print from reference 2, scaled to the product and following its folds |

For a pattern from a second image, pass the source first and the pattern second.

## Colour words

- Name a common colour, then the hex code if the user has one: "navy (#1F2A44)".
- Add one tone word when the name is vague: "warm sand", "cool grey", "deep forest green".
- For black, add "keep the highlights and the visible grain".
- For white or cream, add "keep the seams and the shadow edges".
- For a two-tone product, write one recolour line per zone, such as "Recolour only the body to navy and only the strap to tan."

## When the colour drifts

| Problem | Fix |
|---|---|
| Colour bleeds onto hardware or the logo | Shorten the keep-list to the three most important parts. Name each by place, such as "the gold buckle on the front flap". |
| Texture goes flat or plastic | Add the material words, such as "keep the leather grain and the specular highlights". Try another model. |
| The shape or framing shifts | Remove style words. Keep the guard line exactly. Use the same ratio as the source. |
| Two colours look alike | Add a tone word to each. If they still look alike, suggest colours that are further apart and let the user choose. |
| The background changes colour | Add "the background stays [white / light grey]" to the keep-list. |

Each fix is a new quote, a new approval and a new key, such as `ecom-tote-colour-navy-4x5-v2`.
