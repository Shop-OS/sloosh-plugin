# Banner prompt and fixes

Use this file for the direct path of the `collection-banner` skill. Write one prompt per size. Fill each part in angle brackets from the brief, the brand kit and what you saw with `view_asset`.

## Prompt structure

1. Size and use: "Wide 21:9 store banner for a homepage hero."
2. Products: "The products from references 1 to 3, exactly as shown, each one once, labels facing the camera."
3. True sizes: "Reference 1 is a 50 ml bottle, about 10 cm tall. Reference 2 is a 500 ml jar, about 15 cm tall. Keep these sizes against each other."
4. Placement: "Arranged in a loose group on the right two thirds."
5. Set: "On a travertine shelf against a soft sage wall." Take the colours from the kit in plain colour words.
6. Empty zone: "The left third is empty and calm for a headline: no objects, an even tone, low contrast."
7. Light and lens: "Soft daylight from the left, gentle matching shadows, 50 mm lens, eye level."
8. Limits: "No text, no logos, no extra products, no props that compete with the products."

## Layouts by size

| Size | Layout |
| --- | --- |
| 21:9 desktop | Products grouped in two thirds of the width. The other third stays empty. |
| 16:9 desktop or email | Products grouped in a little over half the width. Keep the empty side at least a third wide. |
| 4:5 mobile | Products grouped or stacked in the lower half. The top third stays empty for the headline. |
| Centre headline | Products split into two small groups at the left and right edges. The centre stays empty. |

## Sets that suit a range

- Skincare or candles: a stone or wood shelf, a plain painted wall, soft side light.
- Food and drink: a kitchen counter or a linen cloth, warm light, one or two loose ingredients far from the empty zone.
- Fashion accessories: a plinth or stacked blocks in one brand colour, clean studio light.
- Seasonal or gift: the brand colours with one seasonal cue, such as a few pine sprigs, kept away from the empty zone.

## Fixes

| Problem | Fix |
| --- | --- |
| A product is missing or doubled | Name each product once with its reference number. Use fewer products per banner. Try a model that takes more reference images. |
| A label is changed or unreadable | Add "labels exactly as reference N, facing the camera". Use a sharper, front-facing product photo. |
| The sizes look wrong | Give each product's height in centimetres. Name the tallest and the smallest. |
| The empty zone has objects or busy texture | Put the empty-zone line first in the prompt. Add "a plain, even wall on that side". |
| The light does not match across products | Name one light direction and "matching shadows for every product". |
| The ratio is not listed by the model | Use the widest landscape ratio it lists. Tell the user the theme can crop it. |
