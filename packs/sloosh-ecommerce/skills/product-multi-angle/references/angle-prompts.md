# Angle prompts

Each view prompt has three parts in this order: the camera line, the studio line and the keep line. Write one prompt per view. Keep the studio line and the keep line the same for every view in a set. Change only the camera words.

## Skeleton

```
The exact product from reference 1, photographed from [the camera position], same scale as the reference.
Centred on a seamless [light grey] studio backdrop, soft even studio light, gentle contact shadow, 50 mm lens.
Shape, colours, materials, logo and every part stay identical to reference 1: [the feature list]. Only the camera position changes. No extra objects, no text.
```

## Camera words by view

| View | Camera words |
|---|---|
| Front | straight on, at the product's mid height, the logo face to camera |
| Three-quarter | turned 45 degrees to the left, camera at mid height |
| Side | a 90-degree side view from the [left / right], camera at mid height |
| Back | directly from behind, camera at mid height, the back panel to camera |
| Top-down | directly above, camera pointing straight down, product centred |
| High angle | 45 degrees from above, front face to camera |
| Low hero | slightly below mid height, looking up a little, front face to camera |
| Base | upturned to show the base, the base flat to camera |
| Open | the lid or flap open, three-quarter view, inside visible |

For a set, name the same side for every side and three-quarter view. Mixed sides break the gallery order.

## Feature list

Name each part by its place on the product. Name the side it is on in the front view. The model then knows where the part goes in other views.

- Logo: "the logo centred on the front panel, 2 cm below the top edge".
- Asymmetric parts: "the pump spout points left", "the zip pull on the right side seam".
- Hardware: "two gold rivets at each strap end".
- Print: "the striped print runs vertically".

## Material words

| Material | Words to add |
|---|---|
| Glass or clear plastic | glass, see-through, same refraction, same liquid level |
| Gloss | high-gloss finish with sharp, small highlights in the same places |
| Metal | brushed metal with the same reflections |
| Fabric | same weave and drape, no new folds or seams |
| Fine print or pattern | the print from reference 2, same scale and direction |

For a fine print, pass the source first and a close crop of the print second.

## When a view drifts

| Problem | Fix |
|---|---|
| A feature moved to the wrong side | Name the side in the feature list for that view, such as "the pump now points right because the camera is behind". |
| The back invents a pocket, a label or a seam | Add "plain back panel, no new features". Ask for a real back photo if one exists. |
| The scale changes across views | Pass one passed view as reference 2. Add "same size in frame as reference 2". |
| The backdrop or the light changes | Copy the studio line word for word. Use the same model and ratio for every view. |
| The logo text breaks | Ask for a sharper source with the logo readable. Do not try to repair text by prompt alone. |
