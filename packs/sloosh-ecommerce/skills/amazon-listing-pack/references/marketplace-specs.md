# Marketplace image guidance

These notes are guidance, not a promise of compliance. Each marketplace changes its image rules. Before the user uploads, tell them to check the marketplace's current image spec for their category. Some categories have extra rules.

Never tell the user that an image is compliant. Say which rules you applied and which ones they must still check.

## Amazon

Check the current product image requirements in Seller Central for the category.

| Rule | Common guidance |
|---|---|
| Main image background | Pure white, read as white to each edge. |
| Main image fill | The product fills about 85% of the frame. |
| Main image content | Only the product for sale. No added text, logos, badges, watermarks, borders or props that are not included. |
| Size | Many sellers aim for at least 1600 px on the longest side so zoom works. Check the current minimum. |
| Secondary images | Lifestyle, scale, detail and callout images are common. Short text is often allowed on secondary images. |
| Claims | No claims the seller cannot support. No marketplace badges or rank labels. |

## Flipkart

Check the current listing image guidelines in the seller dashboard.

| Rule | Common guidance |
|---|---|
| Main image | Usually a white or very light background with the product only. |
| Size | Use a large square image. Check the current minimum. |
| Secondary images | Several angles, details and use scenes are common. |

## Etsy

Check Etsy's current photo guidance in the Seller Handbook.

| Rule | Common guidance |
|---|---|
| First image | Shows as the thumbnail and can be cropped. Keep the product near the centre. |
| Background | No white-background rule. A styled scene is common for the first image. |
| Size | Use a large image. Check the current recommended size. |

For Etsy, offer a styled lifestyle image as the first image, and keep the white image as a later one.

## Own storefront

A storefront has no marketplace rule. Keep one ratio, one light and one background across the catalog. Follow the brand kit. For a Shopify store, the Sloosh Shopify pack has a catalog shoot for many products.

## Other marketplaces

Ask the user for the marketplace's image rules or a link to them. If they have none, apply the Amazon guidance as a safe default and say so.
