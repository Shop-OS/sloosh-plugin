# Space search terms for a lookbook

Search with `list_spaces`. Choose by each Space's description from `get_space`, not by its title. Spaces change on the server, so never pick one from memory.

| Need | Search for | Output type | What the description must say |
|---|---|---|---|
| Studio catalogue set with chosen poses | on-model studio shoot | image | Takes a garment photo and a model; makes several poses on a plain backdrop |
| Editorial frames in a location | fashion editorial | image | Takes a garment photo and a location photo or a place description |
| Flat-lay outfit to poses | flat lay to on model | image | Takes a flat-lay or hanger photo and makes on-model poses |
| Explore poses before the full set | fashion contact sheet | image | Makes a sheet of many poses in one run |
| A full lookbook suite | editorial lookbook | image | Makes studio and editorial frames of one look |
| A regional range, such as ethnic wear | catalogue creation, with the garment type | image | Names the garment type the user shoots |
| A mood or social campaign set | fashion campaign | image | Makes a styled campaign set from a garment photo |
| Motion between two poses | pose to pose video | video | Takes two approved frames or a frame and a pose |
| A short lookbook clip | lookbook video | video | Takes an approved frame or an outfit photo |

## How to choose

- Choose a Space whose description says it takes a garment photo and a model and makes the poses or location the user wants.
- Prefer a Space that takes a model photo when the user has one with consent.
- Prefer a Space with its own model library when the user has no model photo.
- If a Space takes only one pose per run, plan more runs, or use the direct path for the extra poses.
- If the hold for the whole set is more than the allowance left, run the contact sheet first. Let the user pick the poses. Then shoot only those.
- If two Spaces fit, offer both in plain words with what each makes.
