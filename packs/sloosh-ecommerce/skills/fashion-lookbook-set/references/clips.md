# Lookbook clips

Make clips only after the user approves the frames. Clips go in their own round.

1. Search `list_spaces` with output type video and a term from `references/space-search.md`, such as lookbook video or pose to pose video.
2. Follow the SKILL.md Space path steps 2 and 4 to 11. Plan one run per approved frame.
3. Use a key such as `ecom-linen-shirt-lookbook-clip-9x16-v1`.
4. If the set uses a real model photo, the person must have agreed to short clips too. If the user did not confirm that, ask before the clip quote.
5. If no video Space fits, use the product video skill with an approved frame. Do not use the direct image path for a clip.
6. If you can run shell commands, use ffmpeg to extract the first, middle and last frames and look at them. Else ask the user to watch the clip. Tell the user what you did not check.
7. Check that the output ratio and size match the brief. A start frame's ratio drives the clip, so match the start frame to the brief first.
8. For a 9:16 clip, keep the garment and any text out of the bottom 35% of the frame.
