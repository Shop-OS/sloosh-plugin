# Food prompts

Each food prompt has four parts in this order: the dish line, the set line, the camera line and the guard line. Write one prompt per dish and ratio. For a menu set, keep the set line, the camera line and the guard line the same for every dish. Change only the dish line.

## Skeleton

```
Commercial food photograph of [dish name] exactly as in reference 1: the same components ([component list]), the same portion size, garnish tidied, sauce wiped from the rim.
On [a matte dark ceramic plate on a walnut table], with [a linen napkin and a fork], [soft window light from the back left with a gentle fill].
[45-degree angle], 50 mm look, shallow depth of field on the front edge, [ratio] frame.
Natural, appetising colour. No other ingredients. No steam unless the dish is served hot. No added text, no added logos, no hands.
```

Add one brand line at the end when the brand kit has a photo style, such as "warm terracotta surfaces and soft daylight".

## Drink skeleton

```
Commercial drink photograph of [drink name] exactly as in reference 1: the same glass, the same colour of liquid, the same garnish.
Condensation on the glass only if the drink is served cold, clear ice, backlight through the liquid, [dark] background.
[Straight-on angle], 85 mm look, [ratio] frame. No other garnish. No added text, no added logos.
```

## Pack skeleton

Use this for packaged snacks and jars. The pack keeps its real label.

```
Commercial product photograph of [pack name] exactly as in reference 1: the same pack, the same label, logo and colours, readable and unchanged.
On [one colour backdrop from the brand kit], even soft light, the pack facing the camera.
[Straight-on angle], 85 mm look, [ratio] frame. No added text, no added logos. Keep the pack's own label exactly as in reference 1.
```

## Style defaults

Use these when the user gives no style. Say which one you chose.

| Dish type | Default style | Light and set |
|---|---|---|
| Burgers, bowls, salads, brunch | Bright café | Soft daylight, white or pale wood table, light shadows |
| Curries, rice dishes, flatbreads, Mediterranean plates | Rustic natural | Warm side light, linen, aged wood or stone, brass or clay serveware |
| Desserts, cocktails, coffee drinks | Dark moody | One low side light with a rim light, dark slate or deep wood, dark background |
| Packaged snacks and jars | Clean studio | Even soft light, one colour backdrop from the brand kit, the pack facing the camera |
| Sushi, small plates, fine dining | Clean studio | Soft top light, matte stone or dark ceramic, lots of empty space |

## Angles

| Dish shape | Best angle |
|---|---|
| Flat dishes: pizza, bowls seen from above, flat lays, thalis | Top-down, 90 degrees |
| Plated mains, rice dishes, pasta | 45 degrees |
| Tall food: burgers, stacked cakes, sandwiches, drinks | Straight on, 0 to 15 degrees |

Use the table for a single dish. For a menu set, pick one angle that suits most dishes and use it for every dish.

## Placements

| Placement | Ratio | Notes |
|---|---|---|
| Menu or printed menu | 4:3 | Leave a little margin on every side for the menu layout. |
| Delivery app tile | 1:1 | Apps can crop the tile. Keep the whole dish inside the centre with an even margin. Top-down or 45 degrees reads best at small size. |
| Instagram feed | 4:5 | The dish fills the lower two thirds. |
| Story or Reel cover | 9:16 | Keep the dish and any text out of the top 14%, the bottom 35% and 6% at each side. |
| Website hero | 16:9 | Put the dish on one side. Keep the other side calm for the site's own headline. |

## When the dish drifts

| Problem | Fix |
|---|---|
| Added ingredients, such as extra herbs, sesame or cheese | List every component again and add "no other ingredients, no extra garnish". |
| The portion grows or shrinks | Add "the same portion size as reference 1, on the same size of plate". |
| The food looks plastic or too glossy | Add "natural imperfections, real texture, a slight glisten only on sauces". Try another model that takes a reference image. |
| The dark style hides the dish | Add "the dish is lit, the background is dark" and a rim light from behind. |
| Steam or condensation looks fake | Remove it. Add it only for a dish served hot or a drink served cold. |
| Colours look neon | Add "true-to-life colour, no added saturation". |
| The plate or cutlery looks odd | Name one real plate and one piece of cutlery. Remove the other props. |
| Added text or a logo appears | Repeat "no added text, no added logos" at the end of the prompt. For a pack, add "keep the pack's own label exactly as in reference 1". |
| The pack label changes or blurs | Add "the same label, logo and colours, readable and unchanged". |

Each fix is a new quote, a new approval and a new key, such as `ecom-biryani-rustic-4x3-v2`.
