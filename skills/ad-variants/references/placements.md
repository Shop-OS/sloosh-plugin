# Placements and aspect ratios

Use this table to map each placement the user names to an aspect ratio. Check that the model from `list_models` lists the ratio. If it does not, pick another model that lists it, or offer the closest ratio and tell the user.

| Placement | Aspect ratio | Notes |
|---|---|---|
| Instagram and Facebook feed | 4:5 | 1:1 when the user wants one square size for every feed. |
| Instagram and Facebook Stories | 9:16 | Keep the product and text out of the top 14%, the bottom 35% and 6% at each side. |
| Instagram and Facebook Reels | 9:16 | Same safe zone as Stories. |
| TikTok | 9:16 | Same safe zone as Stories. |
| YouTube Shorts | 9:16 | Same safe zone as Stories. |
| LinkedIn feed | 1:1 or 4:5 | Use 1.91:1 for a link post image. |
| Pinterest pin | 2:3 | Leave the top third free for a headline. |
| YouTube, web and display landscape | 16:9 | Use 1.91:1 for a display or link ad when the model lists it. |
| Display or link ad | 1.91:1 | If no model lists it, use 16:9 and tell the user to crop it in the ad tool. |
| Universal square | 1:1 | One size for feeds when the user wants the fewest images. |

## Composition for each ratio

- 9:16: put the product in the middle band. Leave the top and bottom free.
- 4:5 and 2:3: put the product in the lower two thirds. Leave the top third free for a headline.
- 1:1: put the product in the centre. Leave one side or the top free for words.
- 16:9 and 1.91:1: put the product on one side. Leave the other side free for words.

Change the composition for each ratio. Do not crop one image into every size.
