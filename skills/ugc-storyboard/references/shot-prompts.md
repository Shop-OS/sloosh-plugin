# Shot prompts for a UGC storyboard

Use these shapes for the shots of an approved script. Change the words in brackets. Keep one shot in each prompt.

## Plan each shot

| Shot | How to make it |
|---|---|
| The creator holds the product, phone-shot look | A still with the creator photo and the product photo as references. |
| A close-up of the product | A still with the product photo as the reference. |
| A moving shot of a still | A clip that uses the finished still as its start frame. |
| B-roll with no start frame | A clip from the product photo as a reference, if the model takes one. |

A clip that needs a new start frame waits for the second round.

## Still: a phone photo

"Phone photo, slightly imperfect. [The creator from reference 1] holds [the product from reference 2] up to the camera at arm's length in a [bathroom / kitchen / bedroom]. Daylight from a window. Honest expression. The label is readable. Keep the face and the label exactly as in the references. No text."

- Name each reference by its role, such as "reference 1 is the creator" and "reference 2 is the product".
- Ask for a phone-camera look: natural light, a slight tilt, a plain home room. Do not ask for a studio set or perfect light.
- If the user has no creator photo, describe the person in plain words, such as "a woman in her late twenties with short dark hair". Use the same words in every shot.

## Clip: animate a still

"Animate the image. [She turns the bottle to show the label and smiles.] Handheld drift. [4] seconds. Everything else stays the same. No on-screen text."

- Give one action for each clip. Keep the length of each clip to what the script says.
- If the model makes sound, ask for room tone only, with no speech and no music.

## Keep the shots the same

- Use the same outfit, room and light words in every prompt.
- After the first round, use the hero still as a reference for every later shot.
