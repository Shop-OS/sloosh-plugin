# Sloosh pack skills

Each pack adds skills to the core Sloosh plugin. A pack needs the core plugin, installed and connected. Free skills write plans, copy or checks. Paid skills make images or videos, and each one quotes its work and asks for approval first.

Install a pack in Claude Code with /plugin install and the pack name, such as /plugin install sloosh-ads@sloosh, after /plugin marketplace add Shop-OS/sloosh-plugin if that marketplace is not added yet. In the Claude app, open Customize, then Plugins, add the Shop-OS/sloosh-plugin marketplace if it is not there, and install the pack. In Codex, use codex plugin add with the pack name, such as codex plugin add sloosh-ads@sloosh.

## sloosh-motion: Sloosh motion films

Most of these skills render on the user's computer. They need a coding agent that runs commands there, such as Claude Code. In the Claude app, only animated-chart, motion-plates and reference-to-motion work.

Raw talking-to-camera footage that the user shot goes to auto-edit, not to talking-head-video or captions-subtitles (sloosh-video). auto-edit needs macOS on Apple Silicon for the full edit.

| Skill | Use it for | Cost |
|---|---|---|
| `sloosh-motion-director` | The first step for a stylised motion film: it picks the style skill | Paid |
| `reference-to-motion` | A style guide and shot list from a reference video, reel or ad, before any film is made | Free |
| `product-reveal` | A 10 to 20 s launch film for one physical product | Paid |
| `saas-product-video` | A SaaS, app or website film from the real product screens | Paid |
| `kinetic-typography` | A text-led motion film, or a caption layer for another film | Paid |
| `glitch-fx` | A glitch film or glitch transitions | Paid |
| `morph-shapeshift` | A morph film where one subject becomes the next with no cut | Paid |
| `dot-matrix-particles` | A dot-matrix, LED, halftone or particle film | Paid |
| `aura-farming-edit` | A short beat-synced aura edit of one subject | Paid |
| `animated-chart` | An animated chart, count-up number or milestone loop with exact values | Paid |
| `motion-plates` | Still plates for a motion film: backgrounds, cut-outs and hero renders | Paid |
| `motion-film-code` | A film built in code with no voice-over: a sting, a seamless loop or a scored 20 to 45 s film with exact UI and words, in Remotion or HTML pages | Paid |
| `auto-edit` | A finished captioned cut of the user's own talking-to-camera footage: pauses and false starts cut, camera moves, kinetic type and a mastered mix | Paid |
| `reel-export` | A vertical 1080x1920 file from a finished horizontal or square video | Paid |
